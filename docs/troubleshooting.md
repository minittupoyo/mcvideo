# トラブルシューティング

## `/function <名前>:start` で音は鳴るが、壁（絵）が出ない

**壁の一部がワールドの高さ（-64〜319）の外にかかっていませんか？** `fill` は、範囲外を含むと全体が失敗します。
現在のパックは、`start` でマーカーの高さを補正するので、通常は起きません。次の場合は、起きることがあります。

- ワールドの高さ制限が標準と違う（カスタムのディメンション、データパックで高さを変更しているなど）
  → `--min-y` / `--max-y` を、そのワールドの値に合わせて、作り直してください。
- 古い版のパック（補正なし）が入っている → 作り直して、入れ替えてください。

チャットに「その位置はワールド外です」と出ていれば、これです。

**壁の位置までのチャンクが読み込まれていますか？** 画面は正面 `--dist` ブロック先（標準100）に立ち、幅の半分だけ左右に広がります。
そこがロードされていないと、`fill` が失敗します。シミュレーション距離を上げるか、`--dist` を小さくしてください。

## 壁は出るが、動かない / 途中で止まる

- コマンド数の上限のゲームルール（`max_command_sequence_length`、実行文脈数の `max_command_forks`。名前はバージョンによって違うことがあります。既定はどちらも 65536）を確認してください。1フレームのコマンド数が大きい場合（`--width` を大きくした、`full` パレットなど）は、上限に近づく可能性があります。128×72、`color` パレットで試したときは、1フレームの最大が数千コマンドで、既定値には余裕がありました。
- 前の再生が残っている場合は、`/function <名前>:stop` のあとに、`start` を実行してください。

## `/reload` に時間がかかる、エラー表示が出る

大きなデータパック（数MB〜数十MB、数百万コマンド）は、読み込みに数十秒〜数分かかります。クライアントによっては、10秒以上応答しないと、エラーが表示されますが、待てば有効になります。
使わないパックは、ワールドの `datapacks` から外すと、軽くなります。色数を減らす（`--palette plus` など）、解像度を下げる、`--fps` を下げる、のも有効です。

## 音が鳴らない

- リソースパック（`<名前>_audio.zip`）を `resourcepacks` に入れて、**有効にして**ください。
- 有効にしたあとは、**F3+T**（リソースの再読み込み）か、ゲームの再起動が必要です。
- `/playsound <名前>:video master @s` で、単体で鳴らして確認できます。

## 映像と音声がずれる

映像はゲームの tick で進み、音声は実時間で流れます。ゲームが重くなって tick が遅れると、映像が遅れます。
`--fps` を下げる（5 など）、解像度やパレットを下げる、で改善することがあります。

## パーティクル版

- **残像が強い**: `--particle dust`（標準）で、`--scale` を小さくしてください。`end_rod` は寿命が長く、残像が強く出ます。
- **粒が暗い・青い**: 夜はそうなります。標準では `light` ブロックを置いて明るくしています（`--no-lights` で止められます）。画面の近くの地面が照らされる場合は、画面を地面から浮かせてください（`--lift`）。
- **重い**: 粒の数（`--width`）を減らしてください。

## ブロックの壁が、地面に埋まる / 浮く

`--anchor bottom`（標準）では、実行したプレイヤーの足元の高さに、壁の下端が合います。地面より低い部分は、地形を壊さないよう、描かれません。
壁を高い位置に置きたい場合は `--lift`、目線の先を中心にしたい場合は `--anchor gaze` を使ってください。

## ffmpeg が見つからない

`ffmpeg` と `ffprobe` を `PATH` に入れるか、`FFMPEG` / `FFPROBE` 環境変数に、実行ファイルのパスを入れてください（Windows では `C:\ffmpeg` も探します）。
